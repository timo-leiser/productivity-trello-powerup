Verbinde Trello, um die Zeit seit dem letzten Listenwechsel einer Karte anzuzeigen.

Verbindung wird geprüft …

Nur Lesezugriff, bis zum Widerruf. Trello gewährt Lesen auf alle für dein Konto zugänglichen Boards. Productivity lädt nur die Kartenhistorie des geöffneten Boards.

Welche Daten werden gespeichert?

Warnschwellen bleiben als Power-Up-Einstellungen in Trello. Karten werden nicht verändert. Karteninhalte werden nicht an eigene Server oder GitHub übertragen.
