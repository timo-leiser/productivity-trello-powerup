OVERVIEW (EN)
See time in each list with green, orange and red thresholds you set per phase. Free; German interface.

ÜBERSICHT (DE)
Sieh die Zeit pro Phase direkt auf deinen Karten. Mit eigenen Grün-, Orange- und Rot-Schwellen für jede Liste.

FEATURES
- Elapsed calendar time since the last recorded entry into the current list.
- Card-front and card-detail badges, refreshed about every 60 seconds.
- Independent green/orange/red thresholds per list, in hours or days.
- New lists: green at 0, orange at 48, red at 120 hours. Empty disables that color. Existing saved lists keep green disabled until configured.
- List-specific settings via each list's ... menu or a card button; no board button or phase dropdown.
- Existing card history; no fabricated time when history is missing.
- No external account, subscription, advertising, analytics or application server.
- Read-only Trello Auth; token in private member plugin data, settings in shared board plugin data.
- German interface. Browser processing. Static hosting on GitHub Pages.

REVIEW INSTRUCTIONS
1. Add the Power-Up to a test board containing two or more lists and cards.
2. Click Mit Trello verbinden and approve read-only access for your own Trello account.
3. Inspect card front and detail badges. Existing history should show the current stay.
4. Move a card to another list; its current stay restarts from that recorded move.
5. Open ... on a list > Productivity · Warnschwellen ... and choose Stunden (hours).
6. Set green to 0, orange to 0.01 and red to 0.02. Save. A newly created card is green, orange after one minute, and red after two minutes.
7. Empty all three fields for an uncolored elapsed-time badge. Enabled thresholds must increase: green < orange < red.
8. Reload the board: list settings persist. Different lists have independent settings.
9. Use Trello-Verbindung verwalten > Verbindung entfernen to disconnect.
   Revoke authorization in https://trello.com/my/account as well.

LIMITS
Only badges are colored. Calendar time includes nights/weekends and is not paused
by completion or archival. Large boards and rate limits can delay loading.
Each member authorizes separately. Missing history produces an unknown time.
No developer credentials or extra test account are needed for reviewers.
