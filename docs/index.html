FOR YOUR TRELLO BOARD

Your board.
A little clearer.

Productivity is free and needs no separate account. It processes card history in your browser and stores settings in Trello.

Trello directory approval is in progress. Members of the developer workspace can already install and test the Power-Up.

Open the plain-text guide ↗

  1. Add it to a boardAfter approval, find “Productivity” by Timo Leiser in Trello’s Power-Up directory. During review, developer-workspace members can add it under Custom.
  2. Connect to TrelloOpen “Productivity” → “Manage Trello connection”. Approve read-only access so the Power-Up can read card history.
  3. Set the pace for each phaseOpen a list’s ⋯ menu → “Productivity · Time thresholds …”. Set green, orange and red thresholds for that list; leave a field empty to disable that color.
