Anleitung als Textdatei ↗

  1. Zum Board hinzufügenNach der Freigabe findest du „Productivity“ von Timo Leiser im Power-Up-Verzeichnis. Bis dahin können Mitglieder des Entwickler-Workspaces es unter „Benutzerdefiniert“ hinzufügen.
  2. Mit Trello verbindenÖffne „Productivity“ → „Trello-Verbindung verwalten“. Klicke auf „Mit Trello verbinden“ und erlaube den Lesezugriff auf die Kartenhistorie.
  3. Jeder Phase ihre Zeit gebenÖffne „Productivity“ oder das Menü einer Liste. Speichere die Schwellen pro Phase. Ein leeres Feld deaktiviert die jeweilige Warnfarbe.
