PRODUCTIVITY — PRIVATES TRELLO-POWER-UP EINRICHTEN
================================================

1. https://trello.com/apps/admin öffnen.
   Trello Developer Terms selbst prüfen und akzeptieren.
   New wählen. Den Workspace auswählen, dem dein Board gehört.

2. Name: Productivity
   Author: Timo Leiser
   Email / Support: timo@leiser.me
   iframe Connector URL:
   https://timo-leiser.github.io/productivity-trello-powerup/connector.html

3. Folgende acht Capabilities aktivieren:
   - card-badges
   - card-detail-badges
   - board-buttons
   - card-buttons
   - list-actions
   - show-settings
   - authorization-status
   - show-authorization

4. Unter API Key einen API-Key erstellen.
   Allowed origin: https://timo-leiser.github.io
   Return URL (falls abgefragt):
   https://timo-leiser.github.io/productivity-trello-powerup/auth-callback.html

   Nur der öffentliche API-Key wird gebraucht.
   Niemals ein API-Secret oder einen persönlichen Token in GitHub ablegen.

5. Im gewünschten Board: Power-Ups > Hinzufügen > Benutzerdefiniert.
   Productivity hinzufügen. Nur im ausgewählten Workspace verfügbar;
   es ist keine Veröffentlichung im öffentlichen Verzeichnis erforderlich.

6. Im Board den Productivity-Button öffnen > Trello-Verbindung verwalten.
   Den öffentlichen API-Key eintragen und speichern.
   Mit Trello verbinden anklicken und den Lesezugriff erlauben.
   Der Token wird privat in Trello gespeichert.

7. Im Productivity-Button oder über ... an einer Liste die Phase auswählen.
   Orange / Rot in Tagen oder Stunden eintragen, dann Phase speichern.
   Leeres Feld = diese Warnfarbe aus. Beide leer = nur Zeit anzeigen.
   Standard: Orange ab 2 Tagen, Rot ab 5 Tagen.

WIE DIE ZEIT GEZÄHLT WIRD
- Jede Trello-Liste ist eine Phase.
- Es zählt der aktuelle zusammenhängende Aufenthalt seit dem letzten Eintritt.
- Beim Zurückschieben in eine frühere Liste beginnt ein neuer Aufenthalt.
- Kalenderzeit inklusive Nächte/Wochenenden. 1 Tag = 24 Stunden.
- Zeit läuft auch bei geschlossenem Board weiter.
- Archivierung/Abschluss pausiert die Zeit nicht; Karten in archivierten Listen
  oder archivierte Karten sind nicht auf dem offenen Board sichtbar.
- Bestehende Karten werden anhand der verfügbaren Trello-Historie berücksichtigt.
- Fehlende/uneindeutige Historie wird als unbekannt gekennzeichnet.
- Bei ganzen importierten/verschobenen Listen kann die ursprüngliche Historie
  fehlen. Das Power-Up erfindet dann keinen Eintrittszeitpunkt.
- Es werden Badge-Hintergründe orange/rot, nicht die gesamte Kartenfläche.
- Anzeige und Einstellungen werden spätestens nach ungefähr 60 Sekunden
  aktualisiert; große Boards/Rate-Limits können die erste Anzeige verzögern.

VERBINDUNG ENTFERNEN
Productivity > Trello-Verbindung verwalten > Verbindung entfernen.
Freigabe zusätzlich unter https://trello.com/my/account widerrufen.
